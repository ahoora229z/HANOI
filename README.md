# HANOI — برج هانوی تعاملی

یک ویژوالایزر فارسی و واکنش‌گرا برای مسئله کلاسیک برج هانوی، ساخته‌شده با HTML، CSS و JavaScript خالص.

## قابلیت‌ها
- انتخاب ۳ تا ۸ دیسک و محاسبه خودکار حداقل حرکت‌ها (`2ⁿ - 1`)
- شبیه‌سازی خودکار با کنترل سرعت
- حرکت قدم‌به‌قدم و توقف موقت
- نمایش زنده برج‌ها، درصد پیشرفت، زمان و تاریخچه حرکت‌ها
- رابط کاربری دارک و واکنش‌گرا، بدون نیاز به نصب پکیج

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای توسعه راحت‌تر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار
- `index.html` — ساختار صفحه
- `style.css` — ظاهر و واکنش‌گرایی
- `script.js` — الگوریتم بازگشتی و کنترل شبیه‌سازی

## ایده الگوریتم
برای انتقال `n` دیسک، ابتدا `n-1` دیسک به برج کمکی منتقل می‌شود، سپس دیسک بزرگ‌تر به مقصد می‌رود و در پایان `n-1` دیسک روی آن قرار می‌گیرند. رابطه بازگشتی تعداد حرکت‌ها `T(n) = 2T(n-1) + 1` و پاسخ آن `T(n) = 2ⁿ - 1` است.
